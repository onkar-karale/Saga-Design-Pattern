# Checkout Saga Lab — reference solution

Verified: `npm install && npm run typecheck && npm test` (11 passing tests).

Try to build it yourself from the PDF first (Hours 3–7). Use this only to compare.

To run the UI: scaffold a Vite project (`npm create vite@latest checkout-saga-lab -- --template react-ts`),
`npm i @reduxjs/toolkit react-redux redux-saga && npm i -D vitest`, then copy this `src/` over the template's `src/`.
